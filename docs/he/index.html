הורדת KeySwitch

הקלדתם בפריסת המקלדת הלא נכונה? מסמנים את הטקסט, לוחצים על קיצור אחד, ו־KeySwitch מתקנת אותו במקום: עברית ⇄ אנגלית.

בחרו את המחשב שלכם:

בטא 2.1Apple Silicon ו־Intel

KeySwitch ל־Mac

לכל Mac עם macOS 13 ומעלה.

הורדה ל־Mac

KeySwitch-0.2.1.dmg · קובץ התקנה DMG

התקנה

  1. פותחים את קובץ ה־DMG שהורד.
  2. גוררים את KeySwitch אל Applications.
  3. פותחים את KeySwitch מתיקיית היישומים ועוברים על מדריך הפתיחה הקצר (הוא מבקש הרשאת נגישות).
  4. מסמנים טקסט ולוחצים ⇧⌘J.

חתומה ומאושרת על ידי Apple. מתעדכנת אוטומטית. הוראות מלאות

רוב מחשבי Windowsבטא

KeySwitch ל־Windows

מעבדי Intel / AMD ‏(x64). בחרו בזה אם אתם לא בטוחים.

הורדה ל־Windows ‏(Intel / AMD)

KeySwitch-0.1.0-beta.2-windows-x64-setup.exe · קובץ התקנה EXE

התקנה

  1. פותחים את הקובץ שהורד.
  2. Windows יציג "Windows protected your PC" כי הבטא עדיין לא חתומה דיגיטלית: לוחצים More info ואז Run anyway.
  3. ההתקנה היא למשתמש שלכם בלבד, בלי הרשאות מנהל.
  4. מסמנים טקסט ולוחצים Ctrl+Shift+J. KeySwitch נמצאת בסמל ⇄ שליד השעון.

Windows 10 (גרסה 1809 ואילך) או Windows 11. בטא ניסיונית, לא חתומה דיגיטלית. הערות גרסה

Windows על ARMבטא

KeySwitch ל־Windows

מעבדי ARM / Snapdragon ‏(ARM64), למשל מחשבי Copilot+ עם Snapdragon או Surface Pro X.

הורדה ל־Windows ‏(ARM / Snapdragon)

KeySwitch-0.1.0-beta.2-windows-arm64-setup.exe · קובץ התקנה EXE

התקנה

  1. פותחים את הקובץ שהורד.
  2. במסך "Windows protected your PC" לוחצים More info ואז Run anyway (הבטא עדיין לא חתומה).
  3. ההתקנה היא למשתמש שלכם בלבד, בלי הרשאות מנהל.
  4. מסמנים טקסט ולוחצים Ctrl+Shift+J.

Windows 11 על ARM, או Windows 10 על ARM (גרסה 1809 ואילך). בטא ניסיונית, לא חתומה דיגיטלית. הערות גרסה

איזו גרסת Windows מתאימה לי?

פותחים הגדרות ← מערכת ← אודות ומסתכלים בסוג מערכת: "מעבד מבוסס x64" פירושו Intel / AMD; "מעבד מבוסס ARM" פירושו ARM / Snapdragon. רוב המחשבים הם Intel / AMD.

KeySwitch ל־Windows היא גרסת בטא ניסיונית. היא עדיין לא חתומה דיגיטלית, ולכן Windows וחלק מתוכנות האנטי־וירוס עשויים להזהיר, והיא עדיין לא עובדת בכל האפליקציות. כשהמרה נכשלת, הטקסט המקורי נשאר כמו שהיה. נשמח שתדווחו על כל דבר שלא עובד.
