Install

  1. Open the downloaded DMG.
  2. Drag KeySwitch onto Applications.
  3. Open KeySwitch from Applications and follow the short welcome guide (it asks for Accessibility access).

KeySwitch for Windows

Intel / AMD processors (x64). Choose this if you're not sure.

Download for Windows (Intel / AMD)

KeySwitch-0.1.0-beta.2-windows-x64-setup.exe · EXE installer

Install

  1. Open the downloaded file.
  2. Windows warns "Windows protected your PC" because this beta isn't signed yet: click More info, then Run anyway.
  3. Setup installs KeySwitch for your user only, no administrator rights.
  4. Select text and press Ctrl+Shift+J. KeySwitch lives in the ⇄ icon next to the clock.

Windows 10 (1809 or later) or Windows 11. Experimental beta, not code-signed. Release notes

Which Windows version do I need?

Open Settings → System → About and look at System type: "x64-based processor" means Intel / AMD; "ARM-based processor" means ARM / Snapdragon. Most PCs are Intel / AMD.

KeySwitch for Windows is an experimental beta. It's not code-signed yet, so Windows and some antivirus programs may warn you, and it doesn't work in every app yet. When a conversion fails, your original text stays as it was. Please report anything that doesn't work.

Private by design

Conversion happens on your computer and your text never leaves it. No account. Details, including the optional usage statistics: Privacy Policy.
